## 📊 مخرجات V2 (أوسع من V1)

- كل مخرجات V1 (جدول التحليل + الخلاصة + القرار 6 نقاط).
- **تقارير حسب الوضع المختار** من القائمة.
- **تحليلات متقدمة:** Spectrum/Tone، Crosstalk، Impulse Noise، معدلات أخطاء زمنية، Latency تحت الضغط.
- **مقارنة زمنية Before/After** عند إرسال قراءتين.
- **تقرير ISP جاهز للنسخ** لموظف الدعم/السنترال (بالأرقام والأدلة وطلب الفحص المحدد).
- **وسوم الثقة:** كل سبب محتمل معه الدليل + درجة الثقة + البدائل + الاختبار المطلوب لتأكيده.

## ⚖️ قواعد V2 الصارمة

- كل قواعد V1 سارية (لا تخمين، Speedtest≠Sync، CRC بالزمن، FEC ليس عطلاً، لا مسافة من dB تلقائياً، Measurement/Calculation/Estimate/Interpretation).
- **قاعدة التعارض:** عند اختلاف التعليمات، الأحدث/الأخص يقيّد الأعم.
- **قاعدة الثقة:** ممنوع وصف العطل كمؤكد بدون أدلة كافية — يُذكر مستوى عدم اليقين.
- **قاعدة البيانات الناقصة:** `--` أو الغائب = غير متاح، لا يُفسَّر كعطل.
- لا توصية بفتح الراوتر أو تعديل OLT/إعدادات غير مملوكة.

## 💡 مثال عملي للفرق V1 مقابل V2

أرسلت نفس القراءة:
```
Current Down: 40960 kbps / Attainable: 55000 kbps / SNR: 9.2 dB / CRC: 120 / Uptime: 48h
```
- **V1 يعطيك:** نسبة الاستخدام `74.47%` + Headroom `≈14 Mbps` + `2.5 CRC/hour` + تفسير + قرار واحد من 3 + أهم خطوة.
- **V2 يعطيك كل ما سبق +** (إن اخترت الوضع المتقدم): تصنيف مخاطر الاستقرار + سيناريوهات الاستقرار + هل تحتاج Spectrum؟ + مقارنة مع قراءتك القديمة + تقرير ISP جاهز + شجرة فحص تالية.

## 🔀 DSL أم Wi-Fi؟ (نفس V1 مع تعمّق V2)

V2 يفصل 5+ طبقات: نحاس DSL / راوتر وChipset / Ethernet / Wi-Fi / جهاز / ISP / سيرفر الاختبار — ويحدد طبقتك بالدليل لا بالتخمين.

## ❓ أسئلة V2 الشائعة

- **V1 أم V2؟** V1 أخف وأسرع للفحص اليومي. V2 للدقة القصوى والحالات الصعبة والتصعيد للشركة والمقارنات الزمنية.
- **هل V2 يعمل ببرومبت ضخم على كل النماذج؟** الأفضل نموذج يدعم سياقاً طويلاً وصوراً واضحة. لو النموذج ضعيف، استخدم V1.
- **هل يجب إرسال قراءتين؟** ليس إجبارياً، لكن أقسام 42 و47 لا تعمل بدقة إلا بقراءتين (مستقرة مقابل متدهورة / صباح مقابل مساء).
- **الراوتر لا يعرض Spectrum؟** طبيعي — V2 يكتب `البيانات غير كافية` لهذا القسم ويكمل الباقي.
- **الخصوصية؟** نفس V1: أخفِ IP/يوزر/باسورد/هاتف/MAC.

## 🆚 متى تستخدم V2؟

- خطك DSL/VDSL وتريد **أعمق تحليل ممكن** أو ستخاطب الشركة بتقرير رسمي.
- عندك مشكلة متكررة وتحتاج عزل دقيق أو مقارنة قبل/بعد الإصلاح.
- **لو تريد فحصاً سريعاً خفيفاً → V1.** **لو خطك فايبر FTTH → V3.**

> إخلاء مسؤولية: التحليل استرشادي ولا يغني عن الفحص الميداني.
