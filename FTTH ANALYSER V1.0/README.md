## 📌 ما هو هذا الإصدار؟

**FTTH ANALYSER V1.0** مخصص **للألياف الضوئية فقط** (وليس للنحاس DSL):

- `FTTH – Fiber To The Home`
- `GPON / EPON` و `XG-PON / XGS-PON`
- `OLT / ONT / ONU`
- Optical Transmission + Power Budget + Optical Diagnostics + Broadband Optimization

يعمل كـ **Senior Fiber Optic Network Engineer**: يستقبل صور/بيانات الراوتر أو جهاز ONT، يحللها هندسياً، يشخّص الاتصال، يحدد الأسباب المحتملة، ويقدّم حلولاً بالأدلة — مع **التمييز الدائم** بين: مشاكل الإشارة الضوئية / الأجهزة / الشبكة الداخلية / شبكة المزود.

> ⚠️ هذا الإصدار **لا يصلح لخطوط DSL/Nحاس**. لو خطك ADSL/VDSL استخدم V1 أو V2.

## 📥 كيف تحصل على بيانات الفايبر؟

1. ادخل لصفحة ONT (غالباً `192.168.100.1` في أجهزة Huawei / ZTE) أو صفحة الراوتر (غالباً `192.168.1.1`) — تجد العنوان الصحيح على ظهر الجهاز.
2. ابحث عن:
```
Optical Info / ONT Information / OLT Information / Optical Module / PON Status / Fiber Status
```
3. ابحث عن قيم مثل:
```
TX Optical Power (dBm) • RX Optical Power (dBm) • Working Voltage • Bias Current • Temperature • OLT TX • PON Port • Optical Module Type
```
4. صوّر **الجدول كاملاً مع القيم المرجعية** إن ظهرت (Reference Values مهمة جداً في FTTH).
5. لاختبار السرعة: جهاز واحد بكابل Ethernet مباشرة، بدون تحميلات، وسجّل: Down / Up / Idle Ping / Loaded Latency / Jitter / السيرفر / نوع الاتصال.

**خصوصية:** أخفِ IP العام/يوزر/باسورد/هاتف/MAC إن ظهروا.

## 📊 مخرجات V3

- **تقرير الإشارة:** جدول TX وRX مع المرجعية والحالة والهامش.
- **تقرير ONT:** الجهد/التيار/الحرارة والحالة التشغيلية.
- **تقرير OLT/PON:** المتاح فقط بدون استنتاج عطل من الغائب.
- **تقرير السرعة:** نسب التحقيق + Loaded Latency + Bufferbloat.
- **تقرير التركيب:** عيوب مؤكدة مقابل مخاطر مقابل غير قابل للتحقق.
- **الأسباب مرتبة بالأدلة** + التوصيات بالأولوية + **الحكم النهائي من 8 مستويات**.

## 🔀 أين المشكلة غالباً؟ (يفصلها V3 بالدليل)

- TX/RX خارج المرجعية + مشاكل فصل → طبقة ضوئية/تركيب.
- جهد/حرارة غير طبيعية → ONT/تغذية/تهوية.
- إشارة سليمة + Speedtest منخفض سلكياً → Ethernet/راوتر/ISP/سيرفر.
- إشارة سليمة + سلكي ممتاز + لاسلكي سيئ → Wi-Fi.
- Ping طبيعي خامل ومرتفع تحت الضغط → Bufferbloat/إدارة طابور وليس بالضرورة فايبر.

## ❓ أسئلة FTTH الشائعة

- **هل يصلح لـ DSL؟** لا — DSL نحاس له V1/V2.
- **ما الفرق بين dBm وdB؟** dBm قدرة مطلقة (TX/RX)، وdB نسبة — لا تخلطهما.
- **القيمة `--` تعني عطل؟** لا — تعني غير معروضة في الواجهة.
- **RX سليم لكن النت بطيء؟** افحص Ethernet/Wi-Fi/ISP/السيرفر — الإشارة وحدها لا تحسم.
- **هل أنظف الموصل بنفسي؟** لا تعتمد على صورة، ولا تفتح ONT، واترك التنظيف/الفك للفني مع احتياطات الليزر.
- **كم نتيجة Speedtest أرسل؟** واحدة سلكية نظيفة على الأقل + سرعة الباقة + السيرفر، ويفضّل أكثر من نتيجة بظروف موثقة.

## 🆚 متى تستخدم FTTH؟

- أي خط **FTTH / GPON / EPON / XGS-PON** — سواء مشكلة إشارة أو سرعة أو Ping أو تركيب.
- **لو خطك نحاس (حرارة/رطوبة/بوكس/DSLAM...) → V1 للفحص السريع أو V2 للمتقدم.**

> إخلاء مسؤولية: التحليل استرشادي ولا يغني عن الفني المختص. تحذير الليزر: لا تنظر لنهاية الفايبر أو داخل الموصل.
